# 前言

這份手冊給「不熟系統」的負責人使用。每個分頁三段式：

1. **準備動作**——進入這頁前要先確認的事
2. **執行步驟**——一步一步照做
3. **注意事項**——容易踩到的坑

**找不到頁面 / 看不懂按鈕，請對照畫面截圖請工程師補。**

# 一、登入

## 後台網址

`https://satipatthana-reg-eihf.vercel.app/admin`

> 正式上線後會換成正式網址，請以工程師最新提供的為準。

## 帳號角色

| 角色 | 能做什麼 |
|---|---|
| **admin** | 全部功能（含寄信、批准錄取、編輯資料、刪除帳號） |
| **finance** | 食宿管理頁專用（只能更新繳費狀態，不能寄信） |
| **reviewer** | 唯讀，可看所有資料但不能改 |

帳號由工程師建立，**請不要把帳密貼到 LINE/微信群組裡**。

## 登入步驟

1. 開瀏覽器（建議 Chrome 或 Edge），輸入後台網址
2. 自動跳到登入頁，輸入帳號＋密碼，按「登入」
3. 進到後台，網頁右上角會顯示您的角色

> **登出**：每頁右上角有「登出」按鈕。在公用電腦操作完務必登出。

# 三、報名管理

**功能**：審核報名表、標記錄取／不錄取、查看與編輯個別學員資料。

## 準備動作

- 確認您已從學會收到「核准／拒絕」的清單
- 學員報名後會出現在這頁，狀態預設為「審核中」

## 執行步驟

### 1. 篩選與搜尋

頁面上方有：

- **搜尋框**：輸入姓名、Email、繳費碼搜尋
- **狀態 filter**：審核中／已錄取／未錄取／全部
- **居住地 filter**：依國家／地區篩選

### 2. 標記錄取／不錄取

對每位學員，「狀態」欄位是下拉選單，可選：

- **審核中** ← 預設
- **已錄取**：選了之後系統會自動編一個「報名序號 T-001」
- **未錄取**

> ⚠️ 從「已錄取」改回「審核中」或「未錄取」，**報名序號會被自動取消**。

### 3. 編輯學員資料

點該列的「編輯」按鈕，可改：姓名、Email、電話、課程紀錄等。改完按「儲存」。

### 4. 查看詳細

點「詳細」可開啟整份報名表的內容（含 LINE/微信 QR Code）。

## 注意事項

- **報名序號是學會內部用的**，學員看到的是「繳費碼」
- 改錯狀態時，請立即改回；學員若已收信會收到通知
- **不要刪除學員**（沒有刪除按鈕）。要拒絕請改成「未錄取」

# 四、食宿管理（含寄錄取通知信／正式學員通知信／互動報名通知信）

**功能**：列出已錄取學員的食宿登記、編輯、批次寄三種信。

## 準備動作

- 學員已被標為「已錄取」（在報名管理頁標的）
- 確認您要寄哪一種信（見下方說明）

## 三種信件用途

| 信件 | 用途 | 何時寄 |
|---|---|---|
| **錄取通知信** | 通知學員錄取＋繳費＋食宿登記＋快篩 | 標完錄取後立刻寄 |
| **互動報名通知信** | 通知學員互動報名已開放，請去填表 | 委託人決定要開放互動報名時 |
| **正式學員通知信** | 學員資料完整、繳費確認後的最後確認信 | 食宿登記＋繳費都齊全後 |

> 三種信都是「選擇對象 → 批次寄出」的模式。

## 執行步驟（以批次寄錄取通知信為例）

### 1. 進入食宿管理頁

從後台 Dashboard 點「食宿管理」。

### 2. 篩選對象

- 搜尋姓名／Email／繳費碼／報名序號／學號
- 勾「只顯示已分配學號者」可過濾出正式學員

### 3. 勾選學員

每列前面有勾選框。也可以按頂部的「全選本頁」一次勾全部。

### 4. 按批次寄信按鈕

頂部有三顆按鈕，依您要寄的信點對應的：

- 🔵 **批次寄錄取通知（X）** ← X = 您勾選的人數
- 🟡 **批次寄正式學員通知（X）**
- ⚪ **批次寄互動報名通知（X）**

### 5. 確認對話框

會跳出「確定寄出 X 封信？」按確認。

### 6. 等待寄送

按下後系統會逐一寄信，可能需要 30 秒到幾分鐘（看人數）。寄完會顯示「成功 X 封，失敗 Y 封」。

## 編輯個別學員的食宿資料

點該列「編輯」按鈕，可改：

- 學號（手動編 R-001 等）
- 入住／離開日期、交通方式
- 飲食、過午不食、茶點、晚餐
- 上傳的證件（重新上傳或清除）
- 緊急聯絡人、航班資訊

改完按「儲存」。

## 「學號」說明

- **報名序號 T-xxx**：自動編的（學員錄取時系統自動編）
- **學號 R-xxx**：要手動編！從 R-001、R-002 依序給。給學號的目的是寄「正式學員通知信」要用。

> 編學號的時機：學員繳費＋食宿登記都確認 OK 之後。

## 注意事項

- 寄信前請先**測試一封**：用「預覽測試學員」工具寄給自己（見下方第六節）
- 寄錯人不能撤回！請務必先勾選確認後再按
- 失敗的信通常是學員 email 寫錯，請聯絡學會請學員確認
- **互動報名通知信**寄出前要先去「互動報名管理」開啟互動報名（見第五節）

# 五、互動報名管理（最複雜，請仔細看）

**功能**：

1. 開放／關閉互動報名（學員看不看得到表單）
2. 看學員想報名的場次／老師偏好
3. 抽籤決定誰中簽（手動）
4. 指派場次／組別／日期／序號
5. 批次寄中簽通知信

## 準備動作

- 確認委託人已決定要在哪天開放互動報名
- 邀請信已寄出（在食宿管理頁按「批次寄互動報名通知」）

## 互動報名 vs 互動作業 — 兩個分開的東西

| | 互動報名 | 互動作業 |
|---|---|---|
| 誰填 | 全部錄取學員 | **中簽者**才能填 |
| 內容 | 想參加哪幾場集體互動 + 分組老師排序 | 實修狀況 + 想問老師的問題（75 字內） |
| 截止 | 7/15 晚上 8 點 | 課程開始前 |

## 頁面區塊說明

進到互動報名管理頁，由上而下會看到：

```
┌─────────────────────────────────────────────────────────┐
│ 開放狀態列：                                              │
│   [互動報名開放狀態 ✓ 已開放/未開放]                       │
│   [🔧 預覽表單（測試學員）] [關閉/開放互動報名]            │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│ 容量統計（可摺疊）：各場次／分組已分配人數                 │
└─────────────────────────────────────────────────────────┘
┌─────────────────────────────────────────────────────────┐
│ 主表格：列出所有錄取學員 + 想要場次 + 中簽狀態 + 操作      │
└─────────────────────────────────────────────────────────┘
```

## 執行步驟

### 步驟 1：先測試表單長什麼樣（建議）

1. 點頁首的「🔧 預覽表單（測試學員）」按鈕
2. 跳出對話框：「請輸入測試學員 email」
3. **填一個您能收信的 email**（例：你的私人 email）
4. 按 OK，會新分頁開「互動報名」表單，您可以照學員視角操作
5. **送出後資料會真實寫入測試學員的記錄**，請完成一輪後到後台清掉測試資料

### 步驟 2：開放互動報名

1. 在頁首開放狀態列點「**開放互動報名**」按鈕
2. 確認後，狀態切到「✓ 已開放」（綠色）
3. 學員的「會員專區 dashboard」會出現「互動報名」task card
4. 學員開始填表

### 步驟 3：寄邀請信

回到「食宿管理」頁，全選學員，按「批次寄互動報名通知」（見第四節）。

### 步驟 4：等學員填寫到截止（7/15）

期間您可以在這頁的主表格看誰填了、誰沒填：

- **想要的集體場次**欄：學員勾的場次清單
- **想要的分組排序**欄：學員的 1～4 順位
- **未送出**：還沒填的人

可以用 filter 「已送出互動報名」把已填的人篩出來。

### 步驟 5：抽籤分配（截止後）

互動報名截止後，您要：

#### 集體互動（每場 8 人）：

打開頁面中段「**容量統計**」可看每場已分配人數。

對每位「想要 s1（巴山週五）的人」做隨機抽籤，從前 8 人標為中簽，其他標未中簽。

實作方式：
- 在主表格找到該位學員
- 「集體狀態」下拉選「**中簽**」（won）
- 點該列「**編輯指定**」按鈕，在彈出視窗：
  - **指定場次**：選 s1 巴山
  - **互動序號**：填 1～15（或 -1 / 0，依排隊順序）
  - 按「儲存」

#### 分組互動（每老師×每天 8 人）：

依學員的「想要的分組排序」（1=第一意願）依序分配：

- 先處理第一意願報巴山的人，前 8 人中簽分到巴山某天
- 沒中籤的依其第二意願再參加抽籤

實作：
- 「分組狀態」下拉選「中簽」
- 「編輯指定」彈視窗：
  - **指定分組**：選老師
  - **指定日期**：選 8/21、8/22 或 8/23
  - **互動序號**：填序號
  - 按「儲存」

### 步驟 6：批次寄中簽通知信

頁首主工具列勾選對象，按「**批次寄中簽通知信（X）**」。

- 中簽者：信內含「填互動作業」按鈕
- 沒中簽者：信內告知未中簽
- **「都沒中簽」自動跳過不寄**
- **「中簽但場次／組別未指定」自動跳過不寄** ← 提醒您回去補

寄完訊息會顯示：「成功 X 封 / 跳過 Y 封（都沒中）/ 跳過 Z 封（中簽但未指定）」。

## 注意事項（重要）

1. **可先標中簽，過幾天再排場次** — 系統允許您「集體狀態 = 中簽」但「指定場次 = 空」。但這時候別寄信！系統會自動跳過。
2. **指定場次／組別不一定是學員第一意願** — 容量有限，依照您的分配為準。EditModal 會顯示「學員想要：X」做參考。
3. **沒中簽 → 清空** — 如果改成「沒中簽」，已指定的場次／序號會被清空。
4. **重複寄信會覆蓋寄送時間** — 同一個學員可以多次寄信（補寄、更正用）。
5. **預覽測試學員**：請只用一筆，不要建多筆造成混淆。它會自動排除在自動匯出之外。

# 六、互動作業（檢視，不能改）

**功能**：唯讀檢視中簽學員填的互動作業內容，方便老師上課前看。

## 執行步驟

1. 後台 Dashboard 點「互動作業」
2. 列出所有已送出作業的學員
3. 用 filter 篩：
   - 全部
   - 集體中簽
   - 分組中簽
   - 兩個都中
4. 點「檢視」開彈窗看完整作業內容（基本資料 + 集體問題 + 分組問題）

## 注意事項

- 作業有寄送設定，但**會由系統自動寄給對應的指導老師**（在課程前）
- 您**不能在後台改學員的作業內容**——若有錯字請聯絡學員或請工程師處理

# 七、時間表編輯

**功能**：編輯課程五日時間表（早晨經行、上午法談⋯⋯），學員可在會員專區看到。

## 執行步驟

1. 後台 Dashboard 點「時間表編輯」
2. 5 個分頁（8/20、8/21、8/22、8/23、8/24），點要改的日期
3. 對每段時間（例 06:00–07:30）：
   - 修改時間範圍
   - 修改活動內容（例：早晨經行、法談、休息）
4. 加新活動：按「+ 新增時段」
5. 改完按「**儲存**」
6. 頁首有「**公開顯示給學員**」開關
   - 開：學員可看
   - 關：只有後台看得到

## 注意事項

- 改了沒儲存就離開頁面，會跳出確認對話框
- 「公開顯示」沒開的話，學員看不到任何時間表
- 改完發現錯誤可以重複編輯，學員看到的是最新版

# 八、自動匯出排程

**功能**：每天／每週自動把報名統計寄到指定的 email（含 Excel 附件）。

## 執行步驟

### 新增排程

1. 後台 Dashboard 點「自動匯出排程」
2. 按「**新增排程**」
3. 填：
   - **排程時間**：選日期＋時間（例：每天早上 8 點）
   - **收件人**：可填多個 email，用逗號分隔
   - **啟用**：勾選
4. 按「**儲存**」

### 立即執行（不等排程）

每筆排程列旁有「**立即執行**」按鈕，按下會立即跑一次。

### 修改／停用

對每筆排程可：
- 編輯（按「編輯」）
- 停用（取消「啟用」勾選）
- 刪除（按「刪除」）

## 收件人會收到什麼

一封 email + Excel 附件，包含 8 個分頁：

1. 全部（所有學員）
2. 待審核
3. 已錄取未繳費
4. 已繳費
5. 未錄取
6. 食宿登記
7. 互動報名
8. 互動作業

> 「[預覽] 測試學員」會自動排除，不會出現在報表裡。

## 注意事項

- 排程是按設定時間跑的，不會早不會晚
- 如果排程到了但沒收到信：請工程師查 log
- **CRON_SECRET** 是系統自動帶的金鑰，不需要您管

# 九、常見問題 FAQ

## Q1. 我寄錯人了怎麼辦？

寄出去的信不能撤回。請：
1. 立刻用學會公告／LINE 通知學員「忽略剛剛那封信」
2. 重新寄正確的信

## Q2. 學員說沒收到信

依序檢查：
1. 學員 email 是否寫對
2. 學員的「垃圾信箱」（這個常見）
3. 您是否真的寄了（看「通知信」欄位有沒有綠色勾勾）
4. 都沒問題 → 請工程師查 log

## Q3. 我不小心關掉互動報名，學員填到一半的資料會不會掉？

不會。已送出的資料保存在資料庫裡。學員看不到表單，但只要重新開啟，他們就能繼續修改。

## Q4. 我在 EditModal 把學員改成「沒中簽」，但其實是中簽的，怎麼救？

把「集體狀態」或「分組狀態」改回「中簽」，**指定場次／組別／序號要重新填**（系統清空了）。

## Q5. 為什麼自動匯出的 Excel 會多一個叫「[預覽] 測試學員」？

不會。系統會自動排除。如果還是看到，請工程師檢查。

## Q6. 我換了一個負責人，他的帳號要重建嗎？

請工程師建新帳號／停用舊帳號。**請不要共用帳號**。

## Q7. 學員填的內容有錯字（例：自己姓名拼錯）怎麼辦？

到「報名管理」找到該學員 → 「編輯」→ 修改 → 儲存。

## Q8. 我可以一次寄信給「特定一群人」嗎？

可以。在「食宿管理」頁用搜尋／filter 篩出您要的人，勾選「全選本頁」，按對應的批次寄信按鈕。
